# Hero hand illustrations

Generated with the built-in ImageGen tool for this project. Transparent PNGs.
HeroConnection.jsx renders the human-hand source as a flat black circular halftone on Canvas. The left hand mirrors the silhouette. The original colored source is never displayed in the hero. The earlier robot asset is retained as an unused source illustration.

## Prompt set

- Robot: a silver and graphite mechanical hand reaching from the left, extended index finger pointing right, articulated curled remaining fingers, made of connected circular halftone dots with dimensional shading; transparent background, no text, no flower, readable on white.
- Human: a warm peach and rose human hand reaching from the right, extended index finger pointing left, remaining fingers gently curled, made of connected circular halftone dots with dimensional shading; transparent background, no text, no flower, readable on white.

Animation: two staggered monochrome hands reach inward around the hero text in a ten-second loop. Reduced-motion mode shows a static pose. There is no flower.
