# Storefront product illustration

wireless-mouse.png was created using the built-in ImageGen tool. Transparent product illustration, not a photograph of a real listed item.

Prompt: A single isolated premium generic wireless mouse, matte warm ivory white body, central seam, two buttons and black scroll wheel, no logo or writing; above/three-quarter view, vertical orientation rotated 12 degrees clockwise; transparent background, no floor shadow, accessories, hands or text; portrait composition, realistic soft studio lighting.

The interface previews Black, Sand and White via CSS filters. Sample SKU suffixes follow the selected colour. Marketplace prices remain the existing illustrative values. Marketplace links open the marketplace home, not a verified product listing.
